Class 01 · Topic 01

Bootstrap কী? কেন ব্যবহার করবো?

Bootstrap হলো একটি ready-made CSS framework — এতে আগে থেকেই তৈরি করা layout system (grid), সুন্দর component (button, navbar, card, modal) আর অনেক utility class আছে। শুধু সঠিক class বসালেই professional, responsive website তৈরি হয়।

🏠

সহজ বাংলায় — Readymade Furniture

নতুন বাসায় উঠলে দুইভাবে ঘর সাজানো যায়: কাঠমিস্ত্রি ডেকে প্রতিটা আলমারি নিজে বানানো (Traditional CSS), অথবা showroom থেকে তৈরি খাট, সোফা, টেবিল কিনে এনে সাজানো (Bootstrap)।

Showroom-এর furniture দ্রুত পাওয়া যায়, মান ভালো, সব মাপে ফিট করে — Bootstrap-ও তাই।

📘

Technical Definition

Bootstrap is a free, open-source, mobile-first front-end framework that provides a responsive 12-column grid, pre-designed components (navbar, modal, carousel…), utility classes, and a JavaScript bundle for interactive components.

🌐

CSS CDN কী?

CDN (Content Delivery Network) হলো পৃথিবীজুড়ে ছড়ানো server-এর নেটওয়ার্ক। আপনার কাছের server থেকে file আসে, তাই দ্রুত load হয়। আর অন্য site-এর মাধ্যমে আগে load হয়ে থাকলে browser cache থেকেও আসতে পারে।

⚙️

JavaScript bundle কেন?

CSS শুধু “দেখতে কেমন” ঠিক করে। কিন্তু click করলে modal খোলা, ☰ চাপলে menu খোলা, carousel slide হওয়া — এগুলো JavaScript-এর কাজ। JS ছাড়া এসব component দেখা যাবে কিন্তু কাজ করবে না।

Container — content-এর ফ্রেম

ছবি ঝোলানোর আগে যেমন ফ্রেমে বাঁধাই করি, Bootstrap-এ content রাখার আগে container-এ রাখি। Container content-কে মাঝখানে রাখে, দুই পাশে জায়গা দেয় আর বড় screen-এ অতিরিক্ত চওড়া হতে দেয় না।

🖥 BROWSER (পুরো screen)
.container (মাঝখানে, সর্বোচ্চ width সীমিত)
CONTENT (text, image, row, col…)
🖥 BROWSER
.container-fluid (সবসময় 100% চওড়া)

Technical: Containers are the most basic layout element in Bootstrap. They center content horizontally, add horizontal padding (gutter), and set a responsive max-width at each breakpoint.

  • .container — প্রতিটি breakpoint-এ নির্দিষ্ট max-width।
  • .container-fluid — সব screen-এ 100% width।
  • .container-md — md-এর নিচে 100%, md থেকে .container-এর মতো (responsive container)।

Property: m = margin, p = padding

Side: t top, b bottom, s start (বাম), e end (ডান), x বাম+ডান, y উপর+নিচ, (কিছু না) = চারদিকে

Class 01 · Topic 12

Bootstrap Buttons

Button হলো user-কে কাজ করতে বলার দরজা — “কিনুন”, “Save”, “Delete”। Bootstrap-এ btn base class + একটা রং/style class দিলেই সুন্দর button।

🔍 এই code-এ কী হচ্ছে?
btnBase style: padding, border-radius, cursor, hover effect। btn-primary … btn-dangerভরাট রং (solid)। btn-outline-*শুধু border; hover করলে ভরাট হয়। btn-lg / btn-smবড় / ছোট মাপ। disabled (attribute)ধূসর, click করা যায় না। <a> tag-এ .disabled class + aria-disabled="true"। btn-groupকয়েকটা button জোড়া লাগানো একটা group; active = select করা। d-gridভেতরের button পুরো চওড়া।
🌍 Real-world Use

E-commerce: “Buy Now” btn-warning btn-lg; “Add to wishlist” btn-outline-secondary। Admin panel: Edit (btn-sm btn-outline-primary) / Delete (btn-sm btn-outline-danger)। Mobile checkout: d-grid।

❌ Common Mistakes
  • btn ছাড়া শুধু btn-primary — padding ও radius আসে না।
  • Navigation-এ <button>, action-এ <a> — উল্টো। অন্য page-এ গেলে <a class="btn">, কাজ করলে <button>।
  • এক জায়গায় অনেক primary button — user বোঝে না কোনটা আসল কাজ। একটা primary, বাকি secondary/outline।
👨‍🏫 Instructor Note
  • ব্যাখ্যা: Lift-এর button analogy — চাপলে সাড়া দেয়; রং দেখে বোঝা যায় কাজটা কেমন।
  • প্রশ্ন: “Delete account button কোন class? আর Cancel?”
  • Practice: একটা confirm dialog-এর button row বানাতে দিন।

Bootstrap Navbar

Navbar হলো website-এর “রাস্তার সাইনবোর্ড” — logo, menu, button। Desktop-এ menu পাশাপাশি; mobile-এ জায়গা কম, তাই menu লুকিয়ে ☰ toggler দেখায় — চাপলে menu খোলে।

🔍 এই code-এ কী হচ্ছে? — প্রতিটি important class
navbarNavbar-এর base — flex layout, padding। navbar-expand-lglg (992px) থেকে menu পুরো খোলা; এর নিচে collapse হয়ে ☰-এর ভেতরে যায়। bg-body-tertiaryহালকা ধূসর background (dark mode-এও মানায়)। navbar-brandLogo / site-এর নাম। navbar-toggler☰ button; data-bs-toggle="collapse" + data-bs-target="#mainNav" — কোন অংশ খুলবে। collapse navbar-collapseযে অংশ mobile-এ লুকায় ও toggle হয়; id target-এর সাথে মিলতে হবে। navbar-nav › nav-item › nav-linkMenu list, item, link। active + aria-current="page"বর্তমান page চিহ্নিত (দেখতে ও screen reader-এর জন্য)। dropdown / dropdown-toggleSub-menu (Categories)। me-autoMenu-র ডানে সব জায়গা ঠেলে দেয় → Login button একদম ডানে। mb-2 mb-lg-0Mobile-এ menu-র নিচে ফাঁকা, desktop-এ নেই।
🌍 Real-world Use

প্রায় সব website। Scroll করলেও উপরে রাখতে sticky-top, সবসময় ভাসিয়ে রাখতে fixed-top (তখন body-তে উপরে padding দিতে হয়)। Dark navbar: class="navbar bg-dark" data-bs-theme="dark"।

❌ Common Mistakes
  • data-bs-target="#mainNav" আর id="mainNav" না মেলা — ☰ কাজ করে না।
  • JS bundle না দেওয়া — toggler ও dropdown কাজ করে না।
  • Bootstrap 4-এর data-toggle লেখা — v5-এ data-bs-toggle।
👨‍🏫 Instructor Note
  • ব্যাখ্যা: Device preview-তে Mobile → ☰ চাপুন → Desktop দেখান।
  • প্রশ্ন: “navbar-expand-md দিলে menu কখন collapse হবে?” (768px-এর নিচে)
  • Practice: নিজের brand-এর navbar, dark theme ও sticky-top সহ।

Alerts ও Badges

Alert = user-কে গুরুত্বপূর্ণ বার্তা দেওয়া (“Order সফল”, “Password ভুল”) — দেয়ালে টাঙানো নোটিশের মতো। Badge = ছোট লেবেল বা সংখ্যা — জামার দামের ট্যাগ বা মোবাইলের unread message count-এর মতো।

3. Alerts

🔍 এই code-এ কী হচ্ছে?
alert alert-successBase + রং (primary, success, danger, warning, info…)। role="alert"Screen reader-কে জানায় এটা গুরুত্বপূর্ণ বার্তা। alert-dismissible fade showবন্ধ করা যায়, বন্ধের সময় fade animation। btn-close + data-bs-dismiss="alert"✕ button; JS দিয়ে alert সরিয়ে দেয়।

4. Badges

🔍 এই code-এ কী হচ্ছে?
badge text-bg-successসবুজ background ও সঠিক text রং-সহ ছোট label। rounded-pillক্যাপসুল আকৃতি। position-absolute top-0 start-100 translate-middleButton-এর ডান-উপরের কোণায় notification count। visually-hiddenচোখে দেখা যায় না, কিন্তু screen reader পড়ে — “9+ unread messages”।
🌍 Real-world Use

Alert: login error, payment success, maintenance notice। Badge: Facebook notification count, “NEW”/“SALE” product tag, admin panel-এ user status।

❌ Common Mistakes
  • Dismissible alert-এ btn-close দিলেন কিন্তু JS bundle নেই — ✕ কাজ করে না।
  • Bootstrap 4-এর badge-success লেখা — v5-এ text-bg-success (বা bg-success)।
👨‍🏫 Instructor Note
  • প্রশ্ন: “কোন বার্তার জন্য কোন alert রং?” — ৪টা বাস্তব বার্তা বলে students-কে রং বলতে দিন।
  • Highlight: visually-hidden দিয়ে accessibility — অনেকেই জানে না।

Bootstrap Modal

Modal হলো page-এর উপর ভেসে ওঠা একটা ছোট জানালা (popup)। পেছনের page ঝাপসা/অন্ধকার হয়ে যায়, যাতে user শুধু এই কাজে মনোযোগ দেয় — যেমন “আপনি কি সত্যিই delete করতে চান?”

🔍 এই code-এ কী হচ্ছে?
data-bs-toggle="modal"Trigger — এই button চাপলে modal খুলবে। data-bs-target="#loginModal"কোন modal খুলবে — id-র সাথে মিলতে হবে। modal fadeModal-এর মূল wrapper; fade = animation। modal-dialog modal-dialog-centeredজানালার আকার; screen-এর মাঝখানে। modal-sm/lg/xl = মাপ। modal-header / body / footerউপরে title ও ✕, মাঝে content, নিচে action button। data-bs-dismiss="modal"Close button — modal বন্ধ করে। tabindex="-1", aria-labelledbyKeyboard (Esc) ও screen reader-এর জন্য।
🌍 Real-world Use

Login/Signup popup, delete confirmation, product quick-view, cookie consent, image preview।

❌ Common Mistakes
  • Target id ভুল বা একই id দুইবার — modal খোলে না বা ভুলটা খোলে।
  • Modal-এর ভেতরে modal — Bootstrap সমর্থন করে না।
  • অপ্রয়োজনে page load-এর সাথে সাথে modal (popup বিরক্তিকর)।
👨‍🏫 Instructor Note
  • ব্যাখ্যা: Trigger (button) → Target (id) — “কলিং বেল আর দরজা”-র মতো দুইটা অংশের সংযোগ।
  • প্রশ্ন: “Modal বন্ধ করার কয়টা উপায়?” (✕, Cancel, Esc key, backdrop click)
  • Practice: “Subscribe” modal — email field ও Subscribe button।

Accordion — FAQ Section

Accordion বাদ্যযন্ত্রের মতো — ভাঁজ খোলে, ভাঁজ বন্ধ হয়। প্রশ্নে click করলে উত্তর খোলে, অন্যটা খুললে আগেরটা বন্ধ হয়। অনেক তথ্য অল্প জায়গায় রাখার সেরা উপায়।

🔍 এই code-এ কী হচ্ছে?
accordion + id="faqAccordion"পুরো group-এর wrapper। accordion-itemএকটা প্রশ্ন-উত্তর জোড়া। accordion-header › accordion-buttonClick করার অংশ (প্রশ্ন)। বন্ধ অবস্থায় collapsed class। data-bs-target="#faqTwo"কোন body খুলবে — body-র id। accordion-collapse collapse showউত্তরের অংশ; show = শুরুতে খোলা। data-bs-parent="#faqAccordion"একটা খুললে বাকিগুলো বন্ধ। না দিলে একাধিক একসাথে খোলা থাকবে। accordion-bodyউত্তরের লেখা।
🌍 Real-world Use

FAQ page, product specification, course syllabus (module → lesson), mobile-এ footer link group।

❌ Common Mistakes
  • একাধিক item-এ একই body id — একটায় click করলে অন্যটা খোলে।
  • প্রথম item show কিন্তু button-এ collapsed রয়ে গেছে — arrow উল্টো দেখায়।
👨‍🏫 Instructor Note
  • ব্যাখ্যা: Live demo-তে data-bs-parent মুছে দেখান — সব একসাথে খোলা যায়।
  • প্রশ্ন: “নতুন প্রশ্ন যোগ করতে কোন কোন জায়গায় id বদলাতে হবে?” (target, aria-controls, body id)

Carousel — ঘুরতে থাকা banner

Carousel হলো slideshow — ছবির album-এর পাতা উল্টানোর মতো একের পর এক slide আসে। দোকানের সামনের ঘুরতে থাকা LED sign-এর কথা ভাবুন: offer 1 → offer 2 → offer 3।

🔍 এই code-এ কী হচ্ছে?
carousel slide + idCarousel wrapper; slide = slide animation। data-bs-ride="carousel"Page load-এর পর নিজে থেকেই চলতে শুরু করে। carousel-indicatorsনিচের ছোট দাগ — কোন slide চলছে; click করে সরাসরি যাওয়া যায়। carousel-inner › carousel-itemSlides; ঠিক একটায় active থাকতে হবে। d-block w-100ছবি পুরো চওড়া। carousel-caption d-none d-md-blockছবির উপর লেখা; mobile-এ লুকানো, md থেকে দেখা যায়। carousel-control-prev/nextবাম-ডানের তীর; data-bs-slide="prev/next"।
🌍 Real-world Use

E-commerce homepage offer banner, testimonial slider, product image gallery।

❌ Common Mistakes
  • কোনো carousel-item-এ active না দেওয়া — কিছুই দেখা যায় না।
  • বিভিন্ন মাপের ছবি — slide বদলানোর সময় উচ্চতা লাফায়। একই মাপ বা নির্দিষ্ট height + object-fit-cover।
  • গুরুত্বপূর্ণ তথ্য শুধু carousel-এ রাখা — অনেক user প্রথম slide-এর পর দেখে না।
👨‍🏫 Instructor Note
  • প্রশ্ন: “Caption mobile-এ কেন লুকানো ভালো?” (ছোট ছবির উপর লেখা পড়া যায় না)

Bootstrap Dropdown

Dropdown হলো ভাঁজ করা menu — restaurant-এর menu card-এর “Drinks” অংশ খুললে তবেই ভেতরের item দেখা যায়। জায়গা বাঁচে, অথচ সব option হাতের কাছে।

🔍 এই code-এ কী হচ্ছে?
dropdownWrapper (position-এর reference)। dropdown-toggle + data-bs-toggle="dropdown"Dropdown button — click করলে menu খোলে; পাশে ▾ চিহ্ন। dropdown-menuলুকানো menu list। dropdown-itemপ্রতিটি menu item; active / disabled হতে পারে। dropdown-dividerItem-দের মাঝে divider রেখা (<hr>)। dropdown-headerছোট শিরোনাম (click করা যায় না)।
🌍 Real-world Navbar Example

❌ Common Mistakes
  • bootstrap.min.js (Popper ছাড়া) — dropdown খোলে না; bundle দরকার।

👨‍🏫 Instructor Note
  • প্রশ্ন: “Dropdown আর accordion দুটোই লুকানো জিনিস দেখায় — পার্থক্য কী?” (dropdown ভাসে ও বাইরে click করলে বন্ধ; accordion page-এর অংশ হয়ে নিচে খোলে)

Offcanvas — পাশ থেকে বের হওয়া panel

টেবিলের drawer টানলে যেমন ভেতরের জিনিস বেরিয়ে আসে — offcanvas screen-এর পাশ (বাম/ডান/উপর/নিচ) থেকে একটা panel টেনে আনে। Mobile navigation, filter panel, cart sidebar-এর জন্য দারুণ।

🔍 এই code-এ কী হচ্ছে?
data-bs-toggle="offcanvas"Toggle button — panel খোলে/বন্ধ করে। offcanvas offcanvas-startবাম থেকে আসে। -end ডান, -top উপর, -bottom নিচ। offcanvas-header / title / bodyPanel-এর উপরের অংশ, শিরোনাম, মূল content। data-bs-dismiss="offcanvas"Close button। list-group-flushMenu link-গুলো সুন্দর list আকারে। mt-auto (flex column-এ)Checkout button panel-এর একদম নিচে।
💡 Responsive navbar + offcanvas

Navbar-এ collapse-এর বদলে offcanvas offcanvas-end দিলে mobile-এ menu পাশ থেকে slide করে আসে — modern app-এর মতো। Toggler-এ data-bs-toggle="offcanvas"।

❌ Common Mistake

Offcanvas আর collapse-এর attribute মিশিয়ে ফেলা — toggle হবে offcanvas, কিন্তু target-এ class="collapse" দেওয়া; কাজ করবে না।

  • প্রশ্ন: “Modal আর offcanvas-এর পার্থক্য?” (modal মাঝখানে, offcanvas পাশ থেকে; দুটোই overlay)

Bootstrap Tables

Result sheet, attendance register — সারি-কলামে সাজানো তথ্যের জন্য table। Bootstrap শুধু .table দিয়েই সাধারণ HTML table-কে সুন্দর করে দেয়।

🔍 এই code-এ কী হচ্ছে?
tableBase style — padding, border রেখা। এটা ছাড়া অন্যগুলো কাজ করে না। table-stripedএক সারি পর পর হালকা রং — পড়তে সহজ। table-hoverMouse রাখলে সারি highlight। table-borderedসব cell-এ border। table-responsive (wrapper div)ছোট screen-এ table ভেঙে না গিয়ে পাশে scroll হয়। thead.table-dark, tr.table-dangerHeader গাঢ়; fail row লাল। align-middleCell-এর content উল্লম্বভাবে মাঝখানে। scope="col/row", captionAccessibility — screen reader বুঝতে পারে কোনটা header।
🌍 Real-world Use

Admin panel-এর user list, order list, school result, invoice item list। Table-এ layout (page সাজানো) করবেন না — শুধু tabular data।

❌ Common Mistake

table-responsive না দেওয়া — mobile-এ অনেক column-এর table screen থেকে বেরিয়ে পুরো page-এ horizontal scroll তৈরি করে।

Bootstrap Components vs Custom CSS

রান্নায় রেডিমেড মশলা (Bootstrap) দ্রুত ও নির্ভরযোগ্য; কিন্তু বিশেষ রেসিপির জন্য নিজের বাটা মশলা (custom CSS) লাগে। আর বেশিরভাগ সময় — রেডিমেড মশলার সাথে একটু নিজের ছোঁয়া (combine)।

🅱️

Bootstrap component

  • Standard UI: navbar, modal, dropdown, accordion, form
  • Accessibility ও JS behavior দরকার
  • সময় কম, team-এ সবাই চেনে
✍️

Custom CSS

  • Bootstrap-এ নেই এমন design (special hero shape, animation)
  • Brand-এর unique look
  • খুব specific layout (CSS Grid area)
🤝

Combine (সবচেয়ে common)

  • Bootstrap card + নিজের hover animation
  • Bootstrap button + brand color
  • Grid Bootstrap-এর, decoration নিজের

Bootstrap Customization — নিজের brand-এর রূপ

সব Bootstrap site একরকম দেখায় — এই অভিযোগের সমাধান customization। Readymade জামায় দর্জি দিয়ে বোতাম, রং, মাপ বদলানোর মতো।

🎨

পদ্ধতি

  1. Custom CSS file — Bootstrap-এর পরে link করে override।
  2. CSS variables — --bs-* বদলানো (CDN-এও কাজ করে)।
  3. Sass (npm) — $primary ইত্যাদি বদলে নতুন করে build (সবচেয়ে পূর্ণাঙ্গ theme customization)।
🧠

জানা জরুরি

শুধু --bs-primary বদলালে text-primary/bg-primary utility বদলায়, কিন্তু button বদলায় না — কারণ .btn-primary-এর নিজস্ব variable আছে (--bs-btn-bg…)। তাই button আলাদা override করতে হয়।

Before / After Visual Comparison

🔍 এই code-এ কী হচ্ছে?
--bs-primary-rgbtext-primary, bg-primary এই rgb variable ব্যবহার করে — তাই দুটোই বদলাতে হয়। --bs-btn-bg …Button-এর নিজস্ব variable — hover/active state-সহ override। .brand-theme scopeVariable একটা wrapper-এ দিলে শুধু ওই অংশ বদলায় (demo-তে পাশাপাশি তুলনার জন্য)। বাস্তব project-এ এগুলো :root-এ রাখুন — পুরো site-এ brand রং বসে যাবে।
❌ Common Mistakes
  • bootstrap.min.css file নিজেই edit করা — update করলে সব হারাবে।
  • সব জায়গায় !important — পরে নিজের style-ই আর override করা যায় না। Bootstrap-এর পরে link করলে সাধারণত লাগে না।
👨‍🏫 Instructor Note
  • ব্যাখ্যা: bKash (গোলাপি), Grameenphone (নীল) — brand রং-এর গুরুত্ব।
  • প্রশ্ন: “--bs-primary বদলালাম, button কেন বদলালো না?”
  • Practice: নিজের brand color দিয়ে landing page-এর theme বদলাতে দিন।
